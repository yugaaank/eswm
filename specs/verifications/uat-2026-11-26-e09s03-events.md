## Safety first

- Run from a real TTY (VT), **not** inside an existing Wayland/X11 session.
  eswm grabs the VT; the compositor and the display server will settle it like
  two raccoons in one bin.
- Keep a second TTY (Ctrl+Alt+F3) open for recovery.
- Nothing is pushed. The branch stays local until you say otherwise.

## Setup

1. On the TTY, start eswm normally.
2. In another TTY (or a second logged-in session), subscribe:

   ```sh
   export EVT="$XDG_RUNTIME_DIR/eswm-${TACIT_COMP_SOCKET:-eswm-test}.events.sock"
   stat -c '%a %n' "$EVT"
   socat - UNIX-CONNECT:"$EVT" | tee /tmp/opencode/eswm-events.jsonl
   ```

   If `socat` is missing, use `nc -U "$EVT"`.

3. For a second subscriber, run the same `socat` into
   `/tmp/opencode/eswm-events-second.jsonl` and compare later with `diff`.
   Connecting is subscribing; the first line must be `hello`.
