## Safety first

- Run from a real TTY (VT), **not** inside an existing Wayland/X11 session.
  eswm grabs the VT; launching it from your desktop session will fight the
  display server and nobody wins that duel.
- Keep a second TTY (Ctrl+Alt+F3) open so you can recover if the compositor
  exits. You have been here before; the escape hatch is a good habit.
- Nothing is pushed. This branch stays local until you say otherwise.

## Setup

1. On the TTY, start eswm with both a laptop panel and an HDMI monitor connected.
2. In `~/.config/eswm/config.lua`, place HDMI explicitly and give each screen
   its own scale/dock (or omit position to exercise the auto side-by-side
   fallback):

   ```lua
   es.dsp.set_output_position("eDP-1", 0, 0)
   es.dsp.set_output_position("HDMI-A-1", 1920, 0)
   es.dsp.set_output_scale("eDP-1", 1.0)
   es.dsp.set_output_scale("HDMI-A-1", 2.0)  -- optional: prove scales are independent
   es.dsp.set_output_dock_height("eDP-1", 48)
   es.dsp.set_output_dock_height("HDMI-A-1", 56)
   ```

3. Reload config (your usual keybind / `hyprctl reload` compat path).
